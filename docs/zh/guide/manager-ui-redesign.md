# 管理器界面改造

本次在现有 Kotlin、Jetpack Compose、Material 3 与 Compose Destinations 框架内实现。参考 GitHub 的列表对齐和分组、LocationSpoofer 的浅色表面与清晰操作，统一替换旧外观。没有引入 UI 依赖，也没有修改 Root 授权协议、授权持久化规则、安装或模块操作逻辑。

原经典/Expressive 外观切换入口和选择状态已移除；品牌配色、动态配色、深浅色、自定义背景及业务设置保留。少数二级组件仍使用 `isExpressiveUi` 兼容名称，但它不再依据旧偏好切换视觉。

## UI 审查

| Before | After | Why |
| --- | --- | --- |
| 首页反复旋转标志、弹跳更新提示与大幅缩放按钮 | 静态品牌标题、短淡入淡出、原生点击反馈 | 高频操作直接，状态变化清晰 |
| 设置项独立圆角背景、卡片嵌套 | 单层分组表面、对齐图标、细分隔线 | 降低视觉噪声，提高扫描效率 |
| 应用、包名、版本和状态挤在单行 | 标题与辅助文字分级，长内容和操作组可换行 | 支持窄屏与系统字体放大 |
| 多种折叠标题栏与导航外观 | 紧凑工具栏、始终显示标签的底部导航 | 导航层级稳定、内容更集中 |
| 开关行和子开关分别可点击 | 单一原生语义开关目标，装饰图标不重复朗读 | 改善触控、键盘和 TalkBack 操作 |
| 悬浮操作逐项弹出、标签占据固定高度 | 原生锚定菜单、短淡出按钮 | 适配长标签与横屏，遵循系统动画设置 |
| 宽屏内容铺满、表单底部容易被遮挡 | 居中限宽、消费系统栏 padding、IME 避让与列表尾部空间 | 保持可读宽度和操作可达性 |

## 实现位置

- `manager/app/src/main/java/com/anatdx/yukisu/ui/theme/UtilityColors.kt`：中性阅读表面；品牌、错误和操作颜色沿用现有主题。
- `ui/theme/UiStyle.kt`、`Type.kt`：统一形状、原生字体和排版层级。
- `ui/component`：搜索、设置开关、对话框、进度、刷新与悬浮操作。
- `ui/screen` 与 `java/ui/screen`：首页、授权、应用配置、模块、插件、仓库、设置、日志、模板与安装等界面。
- `ui/MainActivity.kt`：窗口、安全区、键盘与内容宽度。

## 验证范围

使用项目现有 Gradle 编译、单元测试和 Lint 任务进行验证。设备未通过 ADB 连接，因此没有将代码检查描述为实机截图验收。

2026-10-01 最终执行 `:app:assembleDebug :app:testDebugUnitTest :app:lintDebug --continue` 成功：Debug 编译与打包通过，51 个现有测试全部通过，Lint 通过，`git diff --check` 通过。最终日志位于 `manager/app/build/reports/ui-redesign-final.log`。初次 Lint 的内部分析异常在源码稳定后未再次出现；清除了旧外观相关的未使用资源后完成最终检查。

独立源码审查检查了共享组件的 inset 消费、搜索焦点、开关语义、宽屏约束与原有操作回调；并对照项目实际使用的 Material 3 源码确认标题栏和导航标签可随测量文字高度增长。

`UtilityPreview.kt` 提供使用真实设置组件的浅色、深色、320dp / 2 倍字体与横屏预览。预览不访问 Root；运行时行为仍需在 Android 设备上验证，包括搜索键盘、TalkBack、系统动画关闭、导航手势区、长名称及授权弹窗。

默认中性配色的静态对比度：浅色正文 14.40:1；浅色辅助文字在白色表面上 6.17:1、较深表面上 4.87:1；深色正文 15.71:1；深色辅助文字在普通/较亮表面上为 8.01:1 / 5.41:1。自定义背景、用户透明度以及系统动态品牌色需要在实际设备上单独验收。
