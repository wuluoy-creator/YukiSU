# ZySU

<img align="right" src="../ZySU-mini.png" width="180" alt="Логотип ZySU">

ZySU — решение для root-доступа в Android на базе KernelSU, созданное как форк [SukiSU-Ultra](https://github.com/ShirkNeko/SukiSU-Ultra). Репозиторий содержит модуль ядра ARM64, компоненты пользовательского пространства на C++17 и Manager на Kotlin / Jetpack Compose.

[English](../README.md) · [简体中文](../zh/README.md) · [日本語](../ja/README.md) · [Türkçe](../tr/README.md) · **Русский**

## Реализованные возможности

- Ядерный `su`, разрешения и профили приложений, проверка подписи Manager, динамические менеджеры и аутентификация SuperKey.
- Установка, включение, отключение и удаление модулей, загрузочные скрипты, WebUI и управление репозиториями.
- Встроенный в ksud контроллер SUMHP: OverlayFS, Magic Mount, SUMH и режим без монтирования. `auto` сначала выбирает подходящий OverlayFS, затем Magic Mount. SUMH выбирается явно. Интерфейсы жизненного цикла внешнего MetaModule сохранены.
- Исправление и восстановление загрузочных образов, прямая инъекция LKM, операции с разделами, AnyKernel3 и редактор ramdisk.
- Правила путей и представлений монтирования SUMH, ADB root, журнал su, настройки среды и диагностика.

Наличие реализации не означает совместимость со всеми устройствами, сторонними модулями или средствами проверки среды.

## Поддерживаемая конфигурация

| Компонент | Требование |
| --- | --- |
| Архитектура | ARM64 / `arm64-v8a` |
| Manager / userspace | Android 12 / API 31 и новее |
| Ядро | Linux 6.1 и новее; готовые LKM предназначены для перечисленных Android GKI KMI |
| Режим сборки | Только `CONFIG_KSU=m`; `CONFIG_KSU=y` не поддерживается |
| Стандартные KMI | `android14-6.1`, `android15-6.6`, `android16-6.12`, `android17-6.18` |

Это матрица сборки, а не перечень проверенных устройств. Версия Android сама по себе не определяет KMI. Старые ядра, другие KMI и non-GKI устройства не входят в область применения готовых файлов. Встраивание LKM в ядро boot также не означает поддержку built-in.

Manager проверяет официальные релизы; канала CI-обновлений нет. В Actions следует загружать итоговый APK из `Manager-arm64-v8a`. Обновление APK само по себе не обновляет модуль ядра в загрузочном образе.

В отчёте об ошибке укажите устройство и прошивку, `uname -r`, KMI, версии Manager / ksud / ядра, способ установки, шаги воспроизведения и журналы. Тесты на компьютере не заменяют проверку загрузки и восстановления устройства.
