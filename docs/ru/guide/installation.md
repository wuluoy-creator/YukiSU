# Руководство по установке

Информацию об установке можно найти в разделе [Документация KernelSU — Установка](https://kernelsu.org/guide/installation.html). Здесь приведены только дополнительные пояснения.

## Установка через загружаемый модуль ядра (LKM)

См. [Документация KernelSU — Установка LKM](https://kernelsu.org/guide/installation.html#lkm-installation).

Для режима LKM в YukiSU требуется устройство Android GKI 2.0 с Linux 6.1 или новее. Ядра версии ниже 6.1 не поддерживаются.

## Установка посредством установки ядра

К сожалению, YukiSU не поддерживает built-in.
